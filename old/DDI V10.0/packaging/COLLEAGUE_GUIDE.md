# DDI V10.0 同事使用说明

## 运行方式

请保留整个 `DDI_V10.0` 分发目录，不要只复制其中的任一 `.exe`。目录中包含稳定的终端版 `DDI_V10.0.exe` 和图形界面版 `DDI_V10.0_GUI.exe`，二者共享商业启停配置、授权文件与运行结果目录。

```powershell
.\DDI_V10.0.exe --menu
```

双击 `DDI_V10.0_GUI.exe` 可打开商业筛选、批量查询和运行观察界面。GUI 使用暖灰琥珀全局玻璃视觉与动态环境光，不依赖桌面壁纸；“启动概览”页显示当前版本与运行环境，“任务网络”页以调度核心、并发槽位、商业和数据类型的分层绽放展示真实任务事件，“运行甘特图”页用于观察阶段时间轨迹。

在左侧可开启“减弱动效”：它会关闭持续呼吸和环境粒子，但不会影响任务状态、日志、网络事实信息或导出结果。任务控制台可保存和读取快捷方案，并可直接启用/停用商业；账号抽屉只允许维护运行期账号、密码及必要连接字段。

指定商业执行查询的示例：

```powershell
.\DDI_V10.0.exe --company "商业名称" --action query_excel --data-type 全部 --start-date 2026-06-01 --end-date 2026-06-30
```

## 结果位置

程序所在目录会自动生成 `runtime`：

| 文件类型 | 目录 |
| --- | --- |
| 导出的 Excel | `runtime\downloads` |
| 本次运行日志 | `runtime\logs` |
| 登录会话文件 | `runtime\cookies` |
| GUI 快捷方案 | `config\gui_presets.json` |

## 授权文件

首次运行前，请向维护者提供本机机器码并获取签发后的 `license.json`。将该文件放到 `config\license.json` 后再运行程序。不要复用其他电脑的授权文件。

## 注意事项

- 不要修改 `config\account_runtime.json` 之外的程序文件。
- 不要删除 `runtime` 中仍需保留的 Excel 或运行日志。
- 个人学习资料、平台抓包和维护过程文件不属于本交付包。
