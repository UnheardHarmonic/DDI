# 公共任务与协议框架

本目录是 DDI 的唯一业务事实来源，负责统一任务请求、日期范围、数据类型选择、平台登录、查询、分页、动态字段、Excel 导出、日志、授权和运行时调度。

## 主要模块

- `task_core.py`：领域对象、任务事件、筛选、并发协调和数据类型大类归并。
- `task_runtime.py`：批量任务运行时与事件拓扑。
- `task_execution.py`：单商业登录、查询、导出和产物编排。
- `platform_registry.py`：平台适配器注册和工厂。
- `platforms`：各商业平台的协议适配器。
- `account_config.py`：商业账号、平台和数据类型能力配置。
- `raw_fields.py`：动态原始字段并集与元数据工作表。
- `download_watcher.py`、`excel_style.py`：文件命名和 Excel 样式。
- `flow_cleaner.py`、`entry_detail.py`：复制用 Excel 与录入明细。
- `print_handler.py`、`task_log.py`：统一控制台和 Excel 日志。

适配器只处理平台协议；公共层负责跨入口一致性和最终文件交付。
