# 项目根目录总览

本目录只保留 DDI 的运行入口、公共框架、配置、展示资源、测试和发布脚本。运行生成的 Excel、日志、Cookie、缓存和历史构建物统一位于 `runtime`，不再散落在根目录。

## 主要入口

- `run_ddi.py`：命令行入口。
- `run_ddi_gui.py`：Qt Quick 图形界面入口。
- `run_ddi_web.py`：本机 FastAPI Web GUI 入口。

## 目录职责

- `config`：运行开关、快捷方案、授权和商业覆盖配置。
- `ddi_framework`：任务领域模型、平台适配器、协议执行、Excel、日志和授权公共层。
- `ui`：Qt QML 与 Web 静态展示资源。
- `docs`：正式运行、发布和目录说明。
- `packaging`：PyInstaller spec 与发布脚本。
- `tests`：公共层和平台适配器回归测试。
- `runtime`：本机生成物、归档和维护者参考资料。

根目录中的 Python 文件只承担入口或系统级展示桥接，不实现平台业务协议。
