# 账号运行配置

本目录保存运行期可变配置，不承载平台协议代码。账号密码、授权文件和本机覆盖配置属于敏感数据，默认不提交版本库。

## 文件说明

- `account_runtime.json`：商业启停、负责人和运行期覆盖信息。
- `gui_presets.json`：Qt/Web 共用的快捷任务方案。
- `license.json`：本机授权文件。
- `local_development.json`：本机开发环境覆盖参数。
- `copy_mappings`：复制用 Excel 的商业字段映射。

公共业务层通过 `account_config.py` 读取这些配置，展示入口不得维护第二份商业清单。
