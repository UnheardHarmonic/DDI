# DDI V14.0 运行产物目录说明

## 使用原则

代码、配置、文档与运行产物必须分离。`run_ddi.py` 默认将查询结果、运行日志和会话文件写入 `runtime`；项目根目录只保留源码入口、配置、文档、展示资源和打包文件。

项目内通过 `--output-dir`、`--log-dir` 或 `--cookie-dir` 指定的自定义目录，如果未位于 `runtime` 下，会自动重定向到 `runtime\custom` 对应分类中。项目外的绝对目录视为用户明确指定的交付位置，保持原路径不变。

## 目录架构

```text
DDI V14.0/
|- config/                       账号运行开关与授权配置
|- ddi_framework/                平台适配器和公共框架代码
|- docs/                         同事使用说明、发布说明和正式交付文档
|- ui/                           Qt QML 与本机 Web 展示资源
|- packaging/                    PyInstaller 打包配置
|- dist/                         当前构建生成的发布目录（可再生）
|- license_tool.py               本地授权文件签名辅助工具
|- runtime/                      本机运行产生的文件，不提交版本库
|  |- downloads/                 默认查询结果与正式 Excel 导出
|  |- logs/                      默认 Excel 运行日志
|  |- cookies/                   登录会话摘要和 Cookie 文件
|  |- custom/                    项目内自定义输出目录的自动归类位置
|  |  |- results/                自定义查询结果与 Excel
|  |  |- logs/                   自定义运行日志
|  |  `- cookies/                自定义会话文件
|  |- work/                      可再生的本机任务工作区
|  |  |- web/                    本机 Web 任务状态、事件和下载索引
|  |  |- temp/                   临时任务缓存
|  |  `- validation/             平台回归验证产物
|  `- archive/                  运行产物归档
|     |- legacy/                旧版根目录运行产物归档
|     `- generated/             历史构建、测试和临时生成物
|     `- personal_reference/    仅维护者保留的个人学习与逆向参考材料
|- run_ddi.py                    命令行入口
`- AGENTS.md                     项目协作规则
```

## 到哪里找文件

| 需求 | 目录 |
| --- | --- |
| 本次默认导出的 Excel | `runtime\downloads` |
| 本次默认生成的运行日志 | `runtime\logs` |
| 登录会话与 Cookie | `runtime\cookies` |
| 使用项目内自定义目录后的结果 | `runtime\custom\results`、`runtime\custom\logs`、`runtime\custom\cookies` |
| GUI 快捷方案 | `config\gui_presets.json` |
| 本机 Web 任务状态与下载索引 | `runtime\work\web` |
| 临时缓存与平台验证材料 | `runtime\work\temp`、`runtime\work\validation` |
| 旧版散落在根目录的历史结果 | `runtime\archive\legacy` |
| 同事使用说明与正式交付文档 | `docs` |
| 维护者个人学习、逆向教程与截图 | `runtime\archive\personal_reference` |

## 临时材料处理

浏览器探针、截图、反向分析缓存、验证 Excel、调试响应、临时 JavaScript/CSS、字节码缓存都属于可再生材料。它们只能在任务期间使用，完成协议验证和交付后应删除，不得留在项目根目录。

`docs` 仅存放同事运行、发布和正式交付需要的文档。个人学习笔记、逆向教程、平台抓包截图和维护过程材料不得放入 `docs`；如需保留，应移入 `runtime\archive\personal_reference` 并标明仅供维护者参考。

需要长期保留的手工导出样本、协议证据或验证文件，应由用户明确要求后移入运行产物归档目录，并附上用途说明；默认不保留。

## 命令示例

默认输出无需指定目录：

```powershell
python -X utf8 .\run_ddi.py --company "商业名称" --action query_excel --data-type 全部 --start-date 2026-06-01 --end-date 2026-06-30
```

项目内需要临时分组时，可使用相对目录。入口会自动归类到 `runtime\custom`：

```powershell
python -X utf8 .\run_ddi.py --company "商业名称" --action query_excel --data-type 配送流向 --start-date 2026-06-01 --end-date 2026-06-30 --output-dir review\june --log-dir review\logs
```

需要交付到项目外位置时，传入绝对目录：

```powershell
python -X utf8 .\run_ddi.py --company "商业名称" --action query_excel --data-type 配送流向 --start-date 2026-06-01 --end-date 2026-06-30 --output-dir "D:\DDI交付\六月" --log-dir "D:\DDI交付\六月\logs"
```
